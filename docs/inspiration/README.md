# مكتبة الاستلهام البحثي والتقني
> Curated Research, EdTech & Open-Source Inspiration Library

هذه المكتبة مرجع داخلي لتوجيه تطوير منصة **Antigravity // Learning Systems & Agent Infrastructure**. تجمع مواقع ومؤسسات ومشاريع مفتوحة المصدر قريبة من جوهر المشروع: علوم التعلم، البحث التربوي التطبيقي، الذكاء الاصطناعي في التعليم، تصميم أنظمة التعلم، أدوات الباحثين، وبناء المنتجات التعليمية.

**الغرض:** دراسة الأنماط والأفكار والبنى وتجارب الاستخدام، ثم ابتكار تنفيذ مستقل يناسب هوية المشروع. هذه الروابط ليست اعتماداً رسمياً أو شراكة أو توصية تجارية، ولا تعني نسخ التصاميم أو الشيفرات.

**آخر مراجعة للمراجع:** 2026-11-09

## 2.2 حوكمة اختيار التصاميم — الاستلهام قبل الاستقرار

**لا يُعتمد أي تصميم أو مكون أو نظام بصري للتنفيذ النهائي قبل اكتمال دورة الاستلهام والمقارنة والترشيح.** ينطبق ذلك على 21st.dev وعلى جميع المواقع والمكتبات المرجعية الأخرى.

### دورة القرار الإلزامية

1. **الاستكشاف:** جمع الأنماط والأفكار من المواقع والمشاريع المدرجة في المختبر، مع السماح بإضافة مراجع جديدة بعد التحقق منها.
2. **التوثيق:** تسجيل كل فكرة واستخدامها وسياقها ومصدرها في بطاقة مرجعية، مع فصل الملاحظة المباشرة عن الانطباع.
3. **المقارنة:** مقارنة البدائل التي تؤدي الوظيفة نفسها، لا مقارنة عناصر مختلفة الوظائف لمجرد تشابهها البصري.
4. **الترشيح:** إعداد قائمة قصيرة توضح مزايا وعيوب كل بديل ومدى توافقه مع هوية Antigravity وبنيته التقنية.
5. **التصور المتكامل:** تركيب تصور بصري ووظيفي موحد للموقع، بدلاً من انتقاء مكونات منفصلة دون نظام.
6. **المراجعة والاعتماد:** عرض الخيارات والتوصية وأسبابها على صاحب المشروع، وانتظار الموافقة قبل اعتماد الاتجاه النهائي.
7. **التنفيذ المرحلي:** بعد الاعتماد فقط، تنفيذ نماذج أولية محدودة، واختبارها، ثم تعميم ما ينجح.

### معايير المفاضلة النهائية

- الاتساق مع رسالة المشروع وهويته البحثية والتربوية.
- جودة تجربة الاستخدام ووضوح المعلومات والتنقل.
- الملاءمة للوظائف الفعلية، لا الجاذبية البصرية وحدها.
- التوافق مع البنية التقنية الحالية وسهولة الصيانة.
- الأداء والاستجابة وإمكانية الوصول.
- اتساق المكونات مع بعضها ضمن نظام تصميم واحد.
- الترخيص وشروط الاستخدام والتكلفة والاعتماد على خدمات خارجية.

### حالات القرار

لكل خيار إحدى الحالات التالية: **قيد الاستكشاف / موثق / قيد المقارنة / مرشح / معتمد من صاحب المشروع / مستبعد**.

وجود المرجع في المكتبة أو حصوله على ترشيح لا يعني اعتماده. ولا يجوز تفسير إدراج 21st.dev على أنه موافقة مسبقة على أي مكون بعينه.

### حدود الصلاحيات

لا تُغيّر الهوية البصرية العامة، ولا تستبدل الخلفية أو التخطيط أو المكونات المشتركة، ولا تضف تبعيات أو تنفذ إعادة تصميم شاملة قبل تقديم تصور المقارنة والحصول على موافقة صريحة.

## 4. بروتوكول دراسة كل مرجع

عند دراسة أي موقع أو مستودع، سجّل النتائج في بطاقة قصيرة تشمل:

1. **الغرض والجمهور:** لمن صُمم؟ وما المشكلة التي يحلها؟
2. **المعلومات والتنقل:** كيف ينظم الصفحات والمحتوى والبحث؟
3. **تجربة الاستخدام:** كيف يعمل على الهاتف والحاسوب؟ وما الذي يجعل الاستخدام واضحاً؟
4. **الوظائف:** ما الميزات القابلة للتبني أو إعادة التصور؟
5. **التقنية والبنية:** الإطار، البيانات، التكاملات، الاختبارات، وإمكانية الوصول؛ بحسب ما هو موثق.
6. **الترخيص:** مراجعة LICENSE وشروط الأصول والعلامات التجارية قبل إعادة الاستخدام.
7. **قرارنا:** استلهام / تجربة نموذج أولي / عدم اعتماد، مع سبب واضح.

### ضوابط الاعتماد

- الروابط هنا **مراجع استلهام** وليست تبعيات تشغيلية للموقع.
- لا نضيف مكتبات أو خدمات أو مفاتيح API لمجرد ورودها في مرجع.
- لا نستنسخ الهوية البصرية أو النصوص أو الأصول المحمية.
- لا ندمج أي مستودع خارجي في المشروع قبل مراجعة الترخيص والأمان والصيانة والتوافق التقني.
- لا ننسب شراكات أو اعتمادات أو نتائج إلى Antigravity دون دليل.
- عند ظهور رابط غير نشط أو تغير المشروع، نحدّث البطاقة بعد التحقق من المصدر الرسمي.
