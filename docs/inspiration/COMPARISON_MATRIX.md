# مختبر مقارنة المراجع — Antigravity

> وثيقة عمل داخلية. هذه المصفوفة تحدد ما ينبغي فحصه، ولا تمثل درجات أو نتائج تدقيق نهائية.

## 1. هدف المختبر

تحويل الروابط المرجعية إلى قرارات تصميم ومنتج قابلة للتتبع: ماذا نتعلم؟ ما الذي يستحق نموذجاً أولياً؟ ما الذي لا يناسب نطاق Antigravity؟

## 2. معايير المقارنة الموحدة

بعد الفحص المباشر، تُقيّم كل جهة من 0 إلى 5 في المعايير التالية، مع رابط دليل لكل درجة:

| المعيار | سؤال التقييم |
|---|---|
| وضوح التموضع | هل يفهم الزائر بسرعة ما الجهة/المنتج ولمن يقدم قيمة؟ |
| بنية المعلومات | هل التصنيفات والتنقل والبحث واضحة وقابلة للتوسع؟ |
| العمق المعرفي | هل المحتوى مدعوم بمصادر وأدلة ومنهجية معلنة؟ |
| فائدة الممارس | هل يحول المعرفة إلى أدوات أو خطوات أو موارد قابلة للاستخدام؟ |
| عرض المشاريع | هل يشرح المشاريع والأثر والمنهج والنتائج بوضوح؟ |
| تجربة الاستخدام | هل التجربة متماسكة وسريعة ومتجاوبة ويمكن الوصول إليها؟ |
| قابلية الاستلهام | هل يمكن تحويل المبدأ إلى حل أصيل ضمن نطاق Antigravity؟ |
| مخاطر التبني | هل توجد قيود ترخيص أو خصوصية أو أمن أو اعتماد تشغيلي؟ (درجة أعلى = مخاطر أقل) |

**النتيجة:** مجموع استرشادي من 40، لا يستخدم منفرداً لاتخاذ قرار. تسجل الثقة منفصلة: مرتفعة / متوسطة / منخفضة.

## 4. مسار تنفيذ كل مراجعة

1. افتح الموقع الرسمي أو صفحة المستودع، وتحقق من أن الرابط يعمل.
2. حدد الجمهور والهدف الأساسي ومسارات الاستخدام.
3. افحص صفحتين أو ثلاثاً تمثل الوظائف الأساسية، لا الصفحة الرئيسية فقط.
4. في GitHub: افحص README وLICENSE وآخر نشاط وIssues وReleases والاختبارات والبنية قبل أي توصية تقنية.
5. التقط أدلة قابلة للتحقق: روابط صفحات أو ملفات أو أقسام محددة، وملاحظات مؤرخة.
6. املأ بطاقة المرجع في [القالب](./REFERENCE_CARD_TEMPLATE.md).
7. سجل الدرجات بعد الفحص، ثم اتخذ قراراً: استلهام تصميمي / تجربة نموذج أولي / مراقبة / استبعاد.

## 5. تحويل الملاحظة إلى قرار منتج

كل ملاحظة يجب أن تنتهي بسطر قرار:

- **المبدأ:** ما الفكرة المجردة التي تستحق التعلم؟
- **التطبيق المقترح:** أين يمكن أن تظهر في Antigravity؟
- **النطاق:** صغير / متوسط / كبير.
- **الأثر المتوقع:** قيمة واضحة للمستخدم، لا مجرد تشابه بصري.
- **المخاطر:** حقوق، أمن، خصوصية، صيانة، أداء، أو تضخم نطاق.
- **القرار:** لا إجراء / بحث إضافي / نموذج أولي / تنفيذ مستقل.

## 6. قواعد الجودة

- لا تضع درجات تقديرية من الذاكرة أو الانطباع الأول.
- لا تعتبر شهرة الموقع أو عدد زياراته دليلاً على جودة كل وظيفة فيه.
- لا تستنتج التقنية المستخدمة من المظهر؛ اذكرها فقط إذا أكدها مصدر موثوق.
- لا تعتبر وجود مستودع تابع لمؤسسة دليلاً على أن الموقع نفسه مفتوح المصدر.
- لا تنسخ النصوص أو التصميم أو الأصول. راجع الترخيص لكل مستودع وأصل على حدة.
- لا تضف أي تبعية أو خدمة خارجية إلى التطبيق نتيجة هذه الدراسة وحدها.
- حدّث حالة المرجع إذا تغير أو أصبح غير متاح، مع الاحتفاظ بتاريخ المراجعة السابقة.
